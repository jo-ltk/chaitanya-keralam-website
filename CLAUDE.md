# Chaitanya Keralam: instructions for AI models

The single source of truth for this site's design is [docs/LANDING-PAGE-DESIGN-SYSTEM.md](docs/LANDING-PAGE-DESIGN-SYSTEM.md).

- Read the complete file before designing, redesigning or restyling any page, section, component or style.
- Follow its tokens, components, accessibility, motion and responsive rules. Do not introduce conflicting visual tokens or patterns.
- Also follow the existing implementation patterns in `components/` and `app/styles/`.
- If a request conflicts with the design system, call out the conflict before proceeding.
- Do not create other design-system, style-guide or skill files. Update the design system document instead.
